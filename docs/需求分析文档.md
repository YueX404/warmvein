## 1. 文档目标

本文档将「思路方案」与「需求列表」中**与供暖管网智慧运行强相关的需求**收敛为一套可开发、可验收的需求条目，作为《系统设计文档》《功能开发文档》的输入。

## 2. 项目背景与目标

城市供暖管网存在热量损耗大、管道腐蚀与泄漏、冻堵、温度失衡、运维低效等痛点。本切片以**2.2 供暖管网智慧运行子模块为绝对核心**，配合若干支撑模块，构建「全时段监测 → 分级预警 → 超前预报 → 预案处置 → 工单闭环 → 运营运维」的供暖安全管控闭环，实现从"事后抢险"向"事前防控"转变。

**切片目标**
- 实现供暖管网运行参数全时段监测与热力/水力在线分析；
- 基于 AI 实现四级预警、周期预报、剩余寿命预测；
- 换热站气候补偿自动调节，降低热损耗与能耗；
- 冻堵/爆管事前处置预案 + 工单闭环；
- 通过大屏、APP、**短信**等多渠道精准推送。

## 4. 功能需求（FR）

### 4.1 主模块 — 2.2 供暖管网智慧运行（完整）

**FR-2.2.1 运行参数实时监测**
- FR-2.2.1.1 监测供回水温度、压力、流量、热量损耗、管道腐蚀速率、补口密封状态；
- FR-2.2.1.2 精准定位泄漏、堵塞点位，并在 GIS/一张图上标注；
- FR-2.2.1.3 支持按热源→一次网→换热站→二次网→用户的层级钻取。

**FR-2.2.2 热网水力平衡分析**
- FR-2.2.2.1 计算各支路实际流量与设计流量比值（平衡度 β），β∉[0.9,1.1] 判定失衡；
- FR-2.2.2.2 输出失衡支路清单与调节建议（开度/泵频）。

**FR-2.2.3 换热站智能控制（气候补偿）**
- FR-2.2.3.1 依据室外气温 tw 与用户室温，计算二次供水温度设定值 Tg_set；
- FR-2.2.3.2 向换热站 PLC/控制器下发调节指令（或人工确认后下发），实现质-量调节；
- FR-2.2.3.3 记录调节动作与效果，形成闭环反馈。

**FR-2.2.4 热损耗精准核算**
- FR-2.2.4.1 按管段计算散热损失 Q_loss = K·π·D·L·(T_avg − T_ambient)；
- FR-2.2.4.2 量化保温层失效带来的热量损失，定位高损管段。

**FR-2.2.5 分户用热异常识别**
- FR-2.2.5.1 识别偷热（流量/耗热显著高于同区域均值）、私自放水（回水温度异常低）、室温不达标（室温<18℃ 且流量正常）；
- FR-2.2.5.2 输出异常用户清单与疑似类型。

**FR-2.2.6 冻堵风险预判**
- FR-2.2.6.1 结合气温预测与供水温度，预判管网冻堵风险；
- FR-2.2.6.2 触发时自动启动防冻预案（提高供水温度/加大流量）。

**FR-2.2.7 停暖恢复仿真**
- FR-2.2.7.1 停暖后基于数字孪生预测复暖时间与升温曲线；
- FR-2.2.7.2 给出升温策略优化建议，保障平稳恢复供热。

### 4.2 配套 — 数据治理与中台（1.2）
- FR-1.2.1 供热主数据建模：管网、设备、换热站、热源、组织机构、地理空间；
- FR-1.2.2 传感数据编码/单位/格式统一规范；
- FR-1.2.3 对外提供标准化数据 API（权限/流控/审计）。

### 4.3 配套 — 分级分类预警引擎（4.1）
- FR-4.1.1 四级预警（蓝/黄/橙/红）自动判定；
- FR-4.1.2 同一区域多源重复预警自动聚合降噪；
- FR-4.1.3 预警根因分析（腐蚀/压力异常/冻堵等）；
- FR-4.1.4 多渠道推送（大屏/APP/短信/工作群）。

### 4.4 配套 — 故障预报与寿命预测（4.2）
- FR-4.2.1 分周期故障预报（主干 4-6 月、支干 3-4 月、支线 1-2 月，以供暖口径映射）；
- FR-4.2.2 管道剩余寿命预测：基于腐蚀速率与壁厚余量；
- FR-4.2.3 设备（阀门/泵/传感器）失效预测。

### 4.5 配套 — 供暖能效与节能优化（8.1 + 8.3）
- FR-8.5.1 供暖热源能耗、管网热损耗、单位供热能耗核算；
- FR-8.5.2 同区域同规模能效对标与差距分析；
- FR-8.5.3 AI 优化运行策略（气候补偿 + 变频调节）持续节能。

### 4.6 配套 — 工单与巡检（9.1 + 9.2）
- FR-9.6.1 预警自动生成工单，按位置/技能/忙闲智能派单；
- FR-9.6.2 工单接单→到场→处置→验收→评价全流程可视化与超时升级；
- FR-9.6.3 基于预警与季节自动生成巡检计划与最优路线。

### 4.7 配套 — 数字孪生与热力仿真（10.1 + 10.2）
- FR-10.7.1 GIS+BIM 构建地下供热管网三维模型，Web 端轻量加载；
- FR-10.7.2 热力仿真：温度场、热损耗仿真计算；
- FR-10.7.3 虚实同步：实时传感驱动孪生体状态。

### 4.8 配套 — 数字化预案（5.1）
- FR-5.8.1 结构化冻堵/爆管/停暖/第三方破坏四类专项预案；
- FR-5.8.2 按预警类型与等级自动匹配并启动预案。

### 4.9 配套 — 公众服务（11.2）
- FR-11.9.1 计划检修/故障停暖提前通知用户；
- FR-11.9.2 用户线上报修与进度查询。

### 4.10 新增 — 短信通知功能
- FR-SMS.1 提供统一短信发送服务，抽象短信网关（阿里云/腾讯云/本地网关可插拔）；
- FR-SMS.2 短信模板管理（预警通知、停暖通知、工单派发、恢复通知）与变量填充；
- FR-SMS.3 与预警引擎联动：蓝/黄级→责任人，橙/红级→责任人+主管+应急，按频次与免打扰策略下发；
- FR-SMS.4 发送记录、状态回执（成功/失败/黑名单）、重试与熔断；
- FR-SMS.5 公众服务停暖通知按用户订阅手机号批量下发；
- FR-SMS.6 敏感信息脱敏（手机号 138****1234），发送鉴权与防滥用限流。

### 4.11 横切 — 系统支撑（14.x）
- FR-14.11.1 多租户数据隔离、菜单/数据/操作三级权限、单点登录；
- FR-14.11.2 服务/设备/资源运行监控与离线告警；
- FR-14.11.3 操作与系统日志全量审计；
- FR-14.11.4 满足等保三级（加密传输、分级分类、脱敏、定期自查）。

## 5. 非功能需求（NFR）

| 类别 | 要求 |
|---|---|
| 性能 | 传感器采集到预警延迟 ≤ 5s（实时流）；大屏聚合查询 P95 ≤ 3s；批量日分析 ≤ 30min |
| 可用性 | 平台 7×24 值守，年可用率 ≥ 99.9%；断网时预警信息离线缓存补传 |
| 安全 | 等保三级；传输 TLS、存储加密；敏感数据脱敏；输入全校验防注入 |
| 兼容 | 兼容外贴式/夹具式非原生传感器；第三方厂商多协议设备接入 |
| 可扩展 | 中台预留供水/燃气/污水等域扩展点，新增域不改动核心闭环 |
| 可维护 | 单一职责分层（控制器→服务→数据）；接口文档化（Swagger）；日志可追溯 |
| 容量 | 单地级市≥10km 管网、≥5000 监测点、时序数据留存 ≥ 3 年 |

## 6. 数据需求

### 6.1 主数据
管网（id/材质/管径/敷设年份/权属）、换热站、热源、阀门、泵、传感器、用户（户号/地址/手机号/换热站归属）、组织机构。

### 6.2 关键指标
供回水温度(℃)、压力(MPa)、流量(t/h)、热量(GJ)、温差(℃)、腐蚀速率(mm/年)、壁厚(mm)、室外温度(℃)、用户室温(℃)、平衡度 β、热损耗(kW)、能耗(kWh)。

### 6.3 接口数据
气象（气温预测）、GIS 空间数据、BIM 模型、短信网关回执、政务监管（上报接口预留）。

- 内部：传感采集→Kafka→实时计算→API；API→大屏/APP/移动端。

- 统一 API 网关：鉴权、限流、审计（FR-1.2.3 / FR-14.11.1）。

## 8. 优先级与验收标准

**优先级（MoSCoW）**
- Must：FR-2.2.1~2.2.7、FR-4.1.1~4.1.4、FR-4.2.1~4.2.3、FR-9.6.x、FR-SMS.x、FR-1.2.x
- Should：FR-8.5.x、FR-10.7.x、FR-5.8.x、FR-11.9.x、FR-14.11.x
- Could：FR-2.2.7 停暖仿真高阶策略优化

**验收标准（示例）**
1. 供暖运行参数监测覆盖率 100%（设计指标项全接入）；
2. 四级预警判定准确率 ≥ 95%，误报率 ≤ 5%（基于历史回放）；
3. 气候补偿调节后单位供热能耗同比下降 ≥ 5%；
4. 冻堵预警提前 ≥ 24h 发出；
5. 工单从生成到派单 ≤ 5min，闭环率 ≥ 98%；
6. 短信发送成功率 ≥ 99%，平均时延 ≤ 10s，脱敏合规 100%。

## 9. 术语
- 一次网/二次网：热源到换热站/换热站到用户侧的供热管网。
- 气候补偿：根据室外温度自动调节二级供水温度的控制策略。
- β 平衡度：支路实际流量与设计流量之比。
- 等保三级：信息安全等级保护第三级。
