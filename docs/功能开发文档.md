## 5. 核心算法实现（示意）

### 5.1 hydraulic_balance.py
```python
def compute_balance(actual: dict, design: dict) -> dict:
    """计算各支路平衡度并判定失衡。"""
    result = {}
    for bid, g_act in actual.items():
        g_des = design.get(bid, 0.0)
        beta = round(g_act / g_des, 3) if g_des else 0.0
        result[bid] = {
            "beta": beta,
            "unbalanced": beta < 0.9 or beta > 1.1,
            "suggest_open": round((1 - beta) * 100, 1) if beta else None,
        }
    return result
```

### 5.2 heat_loss.py
```python
def pipe_heat_loss(K: float, D: float, L: float, Tg: float, Th: float, Tamb: float) -> float:
    """管段散热损失(W)。K:传热系数 W/(m²·℃); D:管径 m; L:长度 m。"""
    T_avg = (Tg + Th) / 2.0
    return K * 3.14159 * D * L * (T_avg - Tamb)
```

### 5.3 climate_compensation.py
```python
def climate_compensate(tw: float, tn: float = 18.0, Tg_d: float = 75.0, tw_d: float = -9.0, dT_d: float = 25.0) -> dict:
    """室外温度 tw → 二次供水温度设定。返回设定值与下发动作。"""
    Tg_set = tn + (Tg_d - tn) * (tw - tn) / (tw_d - tn)
    th_set = Tg_set - dT_d
    return {"TgSet": round(Tg_set, 1), "thSet": round(th_set, 1), "tw": tw}
```

### 5.4 frost_risk.py
```python
def frost_risk(T_supply: float, tw: float, velocity: float, v_min: float = 0.2) -> str:
    if T_supply < 5 and tw < 0:
        return "high"
    if T_supply < 10 and tw < -5:
        return "medium"
    if velocity < v_min:
        return "medium"
    return "low"
```

### 5.5 lifetime.py
```python
def remain_life(W_current: float, W_min: float, v_corr: float) -> float:
    """剩余寿命(年)。W:壁厚 mm; v_corr:腐蚀速率 mm/年。"""
    if v_corr <= 0:
        return float('inf')
    return round((W_current - W_min) / v_corr, 2)
```

## 6. 短信服务功能实现

### 6.1 服务抽象 `services/sms_service.py`
```python
from abc import ABC, abstractmethod
import os, json, redis, time

class SMSSender(ABC):
    @abstractmethod
    def _do_send(self, phone: str, content: str) -> dict:
        ...

class AliyunSMSSender(SMSSender):
    def _do_send(self, phone, content):
        # 调用阿里云 SDK，返回 {success, bizId}
        ...

class LocalMockSender(SMSSender):
    def _do_send(self, phone, content):
        return {"success": True, "bizId": f"mock-{int(time.time())}"}

def get_sender() -> SMSSender:
    kind = os.getenv("SMS_PROVIDER", "local")
    return {"aliyun": AliyunSMSSender, "tencent": TencentSMSSender, "local": LocalMockSender}[kind]()

def mask_phone(phone: str) -> str:
    return phone[:3] + "****" + phone[-4:]

def send_sms(template_code: str, phones: list, vars: dict, redis_cli) -> str:
    """模板填充 + 限流 + 重试 + 脱敏 + 落库。"""
    tpl = load_template(template_code)            # 从 biz_sms_template 读取
    content = tpl.format(**vars)
    batch_id = f"b{int(time.time())}"
    for p in phones:
        key = f"sms:limit:{p}"
        if int(redis_cli.get(key) or 0) > 20:     # 单号日限流
            continue
        for attempt in range(3):                   # 失败重试
            r = get_sender()._do_send(p, content)
            if r["success"]:
                redis_cli.incr(key); break
            time.sleep(2 ** attempt)               # 指数退避
        save_sms_log(batch_id, mask_phone(p), template_code, r)
    return batch_id
```

### 6.2 与预警联动
`alarm_engine` 发布 `AlarmEvent` 时调用 `send_sms`：蓝/黄→责任人；橙/红→责任人+主管+应急；公众停暖→订阅用户批量。免打扰时段跳过责任人短信（仍记日志）。

## 11. 自测与验收要点

- **单元测试**：`algorithm/*` 纯函数（平衡度/热损/气候补偿/冻堵/寿命）给定输入断言输出。
- **接口测试**：用 pytest + FastAPI TestClient 覆盖各 API 入参校验与错误码。
- **短信测试**：`LocalMockSender` 联调模板填充/脱敏/限流/重试；切换真实网关后验证回执。
- **联调**：Kafka→Spark→ES→API→大屏全链路；预警触发→短信+工单+预案端到端。
- **性能**：10k 点/5s 采集下实时指标延迟与日批耗时达标（见需求 NFR）。
- **安全**：等保自查项逐条核验（加密/脱敏/审计/注入防护）。
